jakob2019/ holds the Jakob and Hanika (2019) spectral upsampling coefficient tables as
rgb2spec_opt writes them, one scale and one coefficient table per gamut, float32 values
printed so each parses back to the same float. rgb2spec_opt is built from its source, vendored
in alwan_dev/gendata/tools/rgb2spec, as gendata/tools/datagen/gen_jakob2019_table, and run by
gendata/data/jakob2019_luts.py. src/alwan/api/alwan_jakob2019_fetch.inc reads them as
rgb2spec_fetch does. The Zenodo tables published with the paper are not used.
