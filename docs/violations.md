# Code Quality Violations Report

## Rules Enforced

1. **Never increase tolerance** - If precision doesn't match colour-science/OpenColorIO, fix the implementation
2. **Never hardcode math for tests** - Use colour-science, OpenColorIO result functions, or reference math from trustable source whitepapers
3. **Never hardcode values** - All constants from colour-science, OpenColorIO, or acesdev repo
4. **Never manually modify CSV values** - Always generate from ./gendata scripts
5. **Test inputs in CSV** - Write inputs to CSV, use in C files
6. **Test outputs from colour-science, OpenColorIO, or acesdev** - Generate expected values via these sources
